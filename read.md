# CampusEats

CampusEats is the project for CS 543 Web Services.

## Project Description

CampusEats is a campus food ordering system. It allows users to browse food items, place orders, make payments, and track deliveries.

## Main Users

- Students/Customers
- Food Vendors
- Delivery Staff
- Administrators

## Main Capabilities

- Register/Login
- Browse Catalogue
- Search Food Items
- Check Item Availability
- Place Order
- Cancel Order
- Pay for Order
- Track Order
- Create Delivery
- Update Delivery
- Manage Catalogue

## Assignment 1

Assignment 1 covers:

1. Making HTTP requests using `curl`.
2. Reading HTTP responses and status codes.
3. Analyzing website requests using the DevTools Network panel.
4. Setting up the CampusEats Git repository.
5. Writing a CampusEats project brief.
